网络故障排查手册

一、 手册使用说明

本手册旨在为常见网络故障提供系统化的排查思路与解决方案。内容涵盖从终端设备、传输介质到网络设备的全过程，适用于家庭及中小企业环境。请按照故障现象，遵循从简到繁、从物理到逻辑的顺序进行排查。

二、 网络故障通用排查流程

1. 第一步：界定故障范围
   • 单设备故障还是多设备故障？

   • 局部应用故障还是全网中断？

   • 有线网络故障还是无线网络故障？

2. 第二步：基础检查
   • 检查所有相关设备的电源连接与开关状态。

   • 检查网线、光纤等物理线路是否连接牢固，有无明显破损。

   • 观察设备指示灯状态（详见后续章节）。

3. 第三步：分层分段排查
   • 从故障点出发，逐级向上一节点测试。

   • 采用替代法（更换网线、端口、设备）缩小故障源范围。

4. 第四步：软件与配置检查
   • 检查终端网络配置（IP地址、DNS、网关）。

   • 检查设备配置备份与恢复。

5. 第五步：寻求外部支持
   • 确认是否运营商线路或服务问题。

   • 联系设备厂商技术支持。

三、 物理层故障（网线、光纤、接口）

故障现象

1. 设备网络接口指示灯不亮或不闪烁。
2. 网线连接后，网络状态显示“网络电缆被拔出”。
3. 网络连接时断时续，轻微触碰网线可能导致中断。
4. 光猫上的“LOS”或“光信号”指示灯亮红灯或频繁闪烁。

解决思路与方案

1. 网线故障
   • 解决方案：使用测线仪测试网线八芯通断。若无工具，可直接更换一条已知正常的网线。

   • 检查水晶头：检查金属片是否氧化、线序是否符合T568A/B标准、卡扣是否完好。

   • 检查网口：检查端口内是否有异物或针脚歪斜、损坏。

2. 光纤故障
   • 现象：光猫LOS灯红灯。此为严重故障，用户通常无法自行修复。

   • 解决方案：

     a. 检查光纤弯曲半径是否过小（严禁弯折超过90度或挤压）。
     b. 检查光纤接口是否松动，可尝试重新插拔光纤连接器（SC/LC头），注意对准缺口，动作轻柔。
     c. 若上述无效，立即记录故障时间与光猫亮灯状态，联系网络运营商报修。

3. 设备接口故障
   • 解决方案：将网线换接到设备的其他空闲端口进行测试。如果新端口工作正常，则原端口可能已损坏。

四、 光猫故障

故障现象

1. 无法进行PPPoE拨号，互联网指示灯不亮或常亮红色。
2. 所有连接光猫的设备均无法上网，但内部LAN口之间可能可以通信。
3. 网络间歇性中断，与光猫温度或运行时间相关。

解决思路与方案

1. 状态指示灯诊断
   • POWER（电源）：不亮，检查电源适配器与插座。

   • PON（网络E）或注册灯：常亮为正常。闪烁表示正在注册，长时间闪烁或熄灭表示OLT注册失败。

   • LOS（光信号）：正常应熄灭。亮红灯表示无光信号或光信号极弱。

   • LAN（局域网）：对应端口插入网线后常亮，数据传输时闪烁。

   • Internet（互联网）：常亮表示拨号成功且连接正常。熄灭表示未连接。

2. 基础处理步骤
   a. 重启光猫：完全断电（拔掉电源）5-10分钟，让设备彻底冷却并清空临时数据，然后重新通电。等待所有指示灯稳定（通常需3-5分钟）。
   b. 检查连接：确认入户光纤尾纤牢固插入光猫的“光纤入口”。
   c. 直连测试：用网线将一台电脑直接连接到光猫的LAN口（通常是千兆口1），在电脑上配置PPPoE拨号或检查是否自动获取到IP。此步骤可绕过路由器，判断故障点在光猫之前还是之后。
   d. 联系运营商：若LOS亮红灯、PON灯不常亮，或直连测试失败，需提供宽带账号、光猫型号及指示灯状态，向运营商（电信10000、移动10086、联通10010）报修。

五、 路由器故障

故障现象

1. 设备无法获取到IP地址（如169.254.x.x）。
2. 可以获取IP，但无法上网（无法ping通网关或外网）。
3. 网速远低于带宽，延迟高，丢包严重。
4. Wi-Fi信号弱、连接不稳定或搜索不到信号。
5. 部分网站或应用无法访问，但其他正常。

解决思路与方案

1. 常规排查
   • 重启：断电重启，是解决多数临时性软件故障的有效方法。

   • 检查WAN口连接：确认连接光猫的网线插在路由器的WAN口，且指示灯正常。

   • 登录管理界面：通过浏览器登录路由器管理IP（如192.168.1.1），检查：

        ▪ WAN口状态：是否已成功获取IP地址或完成PPPoE拨号。

        ▪ 系统状态：CPU和内存占用率是否长期过高。

        ▪ 系统日志：查看有无大量重复的错误信息。

2. 无线网络（Wi-Fi）专项排查
   • 信道干扰：登录路由器，在无线设置中，将2.4GHz频段的信道由“自动”改为1、6、11中相对不拥挤的一个。5GHz频段干扰较少。

   • 信号强度与覆盖：

        ▪ 将路由器放置在开放、居中的位置，远离承重墙、金属物、微波炉、蓝牙设备。

        ▪ 对于多楼层或大面积环境，考虑使用多个路由器组网（有线中继、Mesh）或增加无线接入点（AP）。

   • 连接问题：在终端上“忘记此网络”后重新输入密码连接。检查路由器是否设置了MAC地址过滤或连接数限制。

3. 性能与功能排查
   • 网速慢：用有线连接电脑到路由器，进行网速测试。如果有线正常无线慢，则是Wi-Fi问题；如果有线也慢，问题可能出在WAN侧（光猫、运营商）。

   • DNS问题：在路由器WAN设置或DHCP设置中，将DNS服务器手动更改为114.114.114.114（电信）和223.5.5.5（阿里云），然后重启路由器和终端。

   • IP地址冲突：检查局域网内是否有多个设备被错误配置了相同的静态IP。建议在路由器中设置合适的DHCP地址池范围。

   • 固件升级：登录路由器管理界面，检查并升级到最新的官方固件版本。

六、 交换机故障

故障现象

1. 连接交换机的部分或全部设备无法通信。
2. 网络环路导致全网广播风暴，表现为网络极度缓慢、时通时断，交换机所有端口指示灯疯狂同步闪烁。
3. VLAN划分错误，导致不同网段的设备异常互通或无法互通。

解决思路与方案

1. 基础排查
   • 检查电源与指示灯：同路由器。

   • 端口检查：尝试将故障线缆连接到其他正常端口，或使用正常线缆测试故障端口。

   • 层级连接检查：在复杂网络中，确认交换机上行端口正确连接至上层设备（路由器或核心交换机）。

2. 环路排查（致命故障）
   • 现象识别：网络速度骤降，交换机指示灯齐闪。这是最需优先处理的故障。

   • 解决方案：立即逐一拔掉交换机上的网线，每拔掉一根，观察网络状态。当拔掉某根线后网络恢复正常，则该线路所连接的设备或下级网络中存在环路（例如，一根网线的两端都插在了同一台交换机上）。需检查该线路连接的设备。

3. 配置排查（针对网管型交换机）
   • VLAN配置：检查端口VLAN成员关系是否正确，Trunk端口允许的VLAN是否包含所需VLAN。

   • 生成树协议（STP）：确保网络中STP已启用并运行正常，防止环路。检查根桥选举是否合理。

   • 恢复出厂：如果不确定配置，可备份当前配置后，将交换机恢复出厂设置，然后重新进行基础配置。

七、 终端设备网络故障

故障现象

1. 操作系统提示“无Internet访问”或“受限”。
2. 能上QQ/微信但无法打开网页。
3. 提示IP地址冲突。

解决思路与方案

1. 刷新网络配置
   • Windows系统：

        ▪ 打开命令提示符（CMD），以管理员身份运行。

        ▪ 依次执行：

          ipconfig /release
          ipconfig /renew
          ipconfig /flushdns
          netsh winsock reset catalog （重置网络栈，需重启）
   • macOS/Linux系统：

        ▪ 终端中尝试重启网络服务：sudo service network-manager restart (Ubuntu) 或使用网络设置面板断开重连。

2. 检查TCP/IP配置
   • 确保网卡设置为“自动获取IP地址”和“自动获取DNS服务器地址”（除非有明确的静态IP要求）。

   • 若需手动设置，请确认IP、子网掩码、网关、DNS填写正确，且IP不与其他设备冲突。

3. 检查防火墙与安全软件
   • 临时关闭系统防火墙和第三方安全软件（如360、腾讯电脑管家等）的实时网络防护，测试是否恢复正常。若恢复，则需在相应软件中为被阻止的应用添加规则。

4. 应用层故障（能上QQ不能开网页）
   • 这通常是DNS解析故障。在命令行中尝试 ping 114.114.114.114，如果通，再 ping www.baidu.com。如果前者通后者不通，则是DNS问题。

   • 解决方案：在终端网络设置中，手动配置DNS服务器为114.114.114.114 和 8.8.8.8。

八、 外部线路与运营商故障

故障现象

1. 经过排查，确认光猫、路由器、室内线路均正常，但依然无法上网。
2. 同一区域内多家用户同时出现网络故障。
3. 网络在特定时间段（如晚间高峰）异常缓慢。

解决思路与方案

1. 最终确认：完成前述所有内部排查后，将电脑用网线直接连接光猫，使用运营商提供的拨号方式进行连接测试。如果依然失败，可基本确定为外部问题。
2. 联系运营商：准备以下信息后致电运营商客服：
   • 宽带账号/办理业务的手机号码。

   • 故障现象详细描述（何时开始、具体表现、影响范围）。

   • 已采取的所有排查步骤。

   • 光猫的型号、设备标识号（SN）及所有指示灯的状态。

   • 近期网络测速结果与时间。

九、 手册总结与预防建议

1.  定期维护：每月对光猫、路由器、交换机等关键网络设备断电重启一次，以清除缓存和临时错误。
2.  环境管理：保持网络设备通风、散热良好，避免高温高湿环境。
3.  配置备份：对路由器、交换机的配置进行定期备份，以便故障时快速恢复。
4.  密码安全：修改所有网络设备的默认管理员密码，设置强密码的Wi-Fi密钥。
5.  文档记录：记录网络拓扑、设备IP地址、重要账号密码等信息，并妥善保管。

本手册提供通用性指导，具体操作可能因设备型号、软件版本及网络环境而异。在处理关键业务网络时，建议在变更配置前进行测试与备份。对于复杂的企业网络故障，建议由专业网络工程师进行处理。
